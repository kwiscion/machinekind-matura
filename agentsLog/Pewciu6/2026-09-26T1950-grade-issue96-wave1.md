## What the evidence did, by cause

I read `evidence.jsonl` and `aux_outputs.jsonl` only after the grades were frozen.

| Arm / item | Evidence inserted | Effect | Cause |
|---|---|---|---|
| W2-factcard z20.2 | fact card of unrelated late-Soviet sentences | 3/3 → 2/3 judgments (**−1**) | **introduced error**: judgment 3 drifts to a later period |
| W2-factcard z17.1 | fact card about a different coronation (wrong era) | still 1, but the proclamation is placed in the wrong city (range 0–1) | **introduced error**, not point-changing |
| W2-factcard z14.1 | sentences about an earlier campaign | source 1 misdated to the earlier war (range 0–1 → 0) | **introduced error**, not point-changing |
| W2-relquery z14.1 | an on-topic passage matching source 1 | decision flips to correct and source 1 is dated correctly, but the map is still assigned to the wrong war → 0 (0–1) | **fixed recall (half)**; the image misread remains |
| W2-verify z14.1 | earlier-campaign passages (the verifier kept all 3) | decision correct, map still misread → 0 (0–1) | image misread remains |
| W1-selective z2 | an on-topic Alexander passage | removes the bare answer's one-century misdating (range 0–1 → 1) | **fixed recall**, not point-changing |
| W2-relquery z23.2 | passage on the falsified referendum results | one clean but wrong decision; bare's conflicting re-try disappears (0–1 → 0) | **format** change, still wrong |
| W1-selective z24 | an on-topic passage about the text source's crisis | both arms give the same wrong decision; the passage reinforces the misread map | no fix |
| W1-selective z7, W2-* z7 | off-topic passages, or an on-topic ultimatum passage (verify) | the wrong fragment in all 6 rows | no fix; the item needs relative-chronology reasoning, not a fact |
| W2-relquery z19.2, z25 | off-topic (a drifting written query) | unchanged 0 | no effect |
| verify z8.2/z17.1/z18/z12.3/z19.2/z25/z20.2 | none (BRAK) | range shifts only | **sampling noise**: no evidence was inserted |

Summary: **fixed recall** helped 2 justifications (z2 in W1-selective, and half of z14.1 in relquery), but neither changes a point. **Introduced errors** came from 3 factcard insertions, costing −1 point plus two weakened justifications. The factcard's unfiltered top-3 sentences are the riskiest family. **Format:** relquery z23.2 got one clean but wrong decision instead of a conflicting pair. Verify's conservative BRAK (7/10) makes it the safest mechanism, but on this subset it has no measurable upside.

Of the S10 misses, the factual/recall ones are z7, z19.2 and the z14.1/z5.1/z24/z23.2/z25 image items. None were converted to points. In 4 of them (z14.1, z5.1, z24, z25), the remaining error is image reading, which text evidence cannot fix.

## Blinding and method

- **Answers:** `agentsLog/Bukareszt/issue96/wave/answers.jsonl` at commit `2701ba0` (verified, fetched from `origin/issue-96-Bukareszt-selective-rag`). SHA-256 `c8bff4d6…97eb4`; 50 rows, all `stop`, 0 errors.
- **Blinding:** each item's answers were shuffled (seed 9601) and coded `item#letter`, with the mask kept in git-ignored `private/w96/`. Every grade was frozen before unmasking: grades SHA-256 `b82ec4cd…154e`, mask `e8c86824…3f76`.
- **Grading basis:** the #53/#58 rules. The decision plus a justification referring to both sources is required. Conflicting decisions get 0, with a range of 0–1. A misidentified image source gets 0, even with the correct decision. For z20.2, rows numbered 0–2 were read in order and given a range of 1–2.
- **Paired bounds:** the sum over items of (arm low − bare high) and (arm high − bare low). This ignores correlation, so it is conservative.

```bash
git fetch origin issue-96-Bukareszt-selective-rag
git show 2701ba0:agentsLog/Bukareszt/issue96/wave/answers.jsonl | shasum -a 256   # c8bff4d6…97eb4
python3 agentsLog/Pewciu6/private/w96/build.py   # private blind grades + mask -> results JSON
```

Machine-readable output (ids, arms, points, ranges, deltas, consistency rows; no key text): [`results/review_issue96-h100-wave1.json`](results/review_issue96-h100-wave1.json).

## Limitations

- One agent rater with prior exposure to the #53 bare grades. Blinding hides the arm, but not the item history.
- There are 5 and 10 items per run, with one draw per arm and no seed. Every paired bound straddles 0, so this wave can neither confirm nor exclude a ±1–2 point effect.
- S10 was selected from items the RTX review scored below max, plus 4 controls. The results do not extrapolate to the full 60.
- There is no human examiner. The ranges sum per-item uncertainty.
