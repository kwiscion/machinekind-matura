# Repair instructions — repair_v2

You receive records that failed strict verification (`verify_strict_v2.md`) together with both judges' notes. For each failing record, either repair it or drop it.

A repair may change ONLY `prompt` and `answer`. The `evidence` claims are fixed; do not add, remove, or edit them.
- Remove every fragment the Lens S judge listed, and anything else not stated in the claims.
- Fix Lens Q issues: name the event, person, or period in the prompt so it stands alone, using only names and dates that appear in the claims or in the record's `topic` (the article title); complete the answer; write fluent, correct Polish; make an `essay_plan` prompt ask for exactly as many points as the claims can support (3–5), each point carrying a fact from a claim.
- Every year in the answer must appear inside a claim.
- Keep the matura register: precise, concise, justified.

Drop the record if the claims cannot support a complete, non-trivial answer to a standalone question.

Records that passed both lenses are copied through unchanged.
